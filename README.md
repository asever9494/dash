# 전국 공공시설 개방정보 대시보드

CSV 파일을 업로드하면 전국 공공시설 개방정보를 브라우저에서 바로 분석하는 정적 웹 대시보드입니다.

**웹사이트:** https://asever9494.github.io/dash/

## 사용 방법

1. 웹사이트를 엽니다.
2. **CSV 파일 선택**을 누르거나 CSV를 업로드 영역에 끌어다 놓습니다.
3. 분석 결과와 차트, 지도, 상세 검색을 확인합니다.
4. 새 자료를 분석하려면 다른 CSV 파일을 다시 선택합니다.

CSV는 서버로 전송되지 않고 사용자의 브라우저 안에서만 처리됩니다.

## 주요 기능

- 전체 시설 수, 유료 시설 비율, 평균 수용인원·사용료, 주말 운영 시설 수, 면적 중앙값
- 시설 유형별 분포 차트와 자동 요약
- 수용인원과 시간당 사용료 비교
- 수용인원 상위 5개 및 시간당 이용료가 낮은 시설 상위 5개
- 주말 운영 여부 분석
- 위도·경도 기반 시설 지도
- 시설명·주소·관리기관 검색
- 시설 유형, 유료/무료(Y/N), 주말 운영 여부 필터
- 주요 컬럼의 유효 데이터 비율 확인

상세 표는 최대 500건, 지도는 최대 1,800건을 표시합니다.

## 지원 파일과 인코딩

- 파일 형식: 헤더가 있는 `.csv`
- 지원 인코딩: UTF-8, UTF-8 BOM, CP949/EUC-KR 계열
- 쉼표가 포함된 값은 CSV 규칙에 따라 큰따옴표로 감싸야 합니다.

## 필요한 데이터 컬럼

아래 컬럼명이 원본 CSV의 첫 행에 있어야 주요 기능이 정상 작동합니다.

| 컬럼명 | 사용 기능 |
|---|---|
| `개방시설명` | 시설 식별, 검색, 순위, 상세 표 |
| `개방시설유형구분` | 유형별 차트와 필터 |
| `유료사용여부` | 유료/무료 비율과 Y/N 필터 |
| `사용료` | 평균 사용료와 비용 분석 |
| `수용가능인원수` | 평균 수용인원, 순위, 산점도 |
| `면적` | 면적 중앙값 |
| `주말운영시작시각` | 주말 운영 여부 |
| `주말운영종료시각` | 주말 운영 여부 |
| `위도` | 지도 표시 |
| `경도` | 지도 표시 |

다음 컬럼도 있으면 해당 정보와 분석이 더 충실해집니다.

| 컬럼명 | 사용 기능 |
|---|---|
| `사용기준시간` | 시간당 사용료 계산 |
| `평일운영시작시각`, `평일운영종료시각` | 상세 표의 평일 운영시간 |
| `소재지도로명주소` 또는 `소재지지번주소` | 주소 검색과 상세 표 |
| `관리기관명` | 관리기관 검색 |
| `사용안내전화번호` | 상세 표 연락처 |
| `데이터기준일자` | 데이터 기준일 표시 |

컬럼명은 위 표와 정확히 같아야 합니다. 숫자 컬럼의 쉼표와 단위 문자는 제거해 숫자로 변환하며, 주말 운영은 시작·종료시각이 모두 입력된 경우로 판단합니다.

## 실행 환경

별도 설치 없이 최신 Chrome, Edge 등 일반적인 웹 브라우저에서 사용할 수 있습니다. 차트, 지도, CSV 처리를 위해 외부 라이브러리를 불러오므로 최초 실행 시 인터넷 연결이 필요합니다.
